ABOUT THE PROJECT

Recommendations
through clustering.

This project uses unsupervised machine learning to discover groups of similar movies and TV shows and uses those groups to generate recommendations.

01 / DATA

Netflix Titles

The model is trained on a Netflix titles dataset containing information such as content type, genres, maturity rating, release year, and duration.

02 / MACHINE LEARNING

K-Means Clustering

K-Means groups titles according to their encoded features. The project first creates four main clusters and then performs additional clustering inside those groups to discover more specific segments.

03 / RECOMMENDATION

How It Works

01

Enter information about a recently watched title.

02

The input is transformed using the same preprocessing used during model training.

03

K-Means determines the main cluster and its corresponding sub-cluster.

04

Titles belonging to the matching cluster are returned as recommendations.
